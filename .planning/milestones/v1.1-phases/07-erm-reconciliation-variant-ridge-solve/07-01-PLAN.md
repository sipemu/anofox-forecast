<objective>
Add empirical-risk-minimization (ERM) hierarchical reconciliation to `src/hierarchy/mod.rs` as a
backward-compatible additive `ReconciliationMethod::Erm { lambda }` variant (ERM-01), fed by a
training-history builder API (ERM-02), computing the regularized ridge projection
`P = B'Ŷ(Ŷ'Ŷ + λI)⁻¹` with reconciled bottom = `P·ŷ` and reconciled all = `S·P·ŷ` (ERM-03),
proven correct against the reference formula on a hand-computed small hierarchy within 1e-10 (ERM-05).

Fixed-λ only. Auto-λ (ERM-04) and grouped end-to-end validation (ERM-06) are Phase 8 — OUT of scope.

Purpose: deliver a fixed-λ ERM solve proven correct where the solve lands, so Phase 8 auto-λ can
layer on top without restructuring.
Output: the enum arm, two `HierarchyTree` fields, the `with_erm_training` setter, the private
`erm_reconcile` fn, and four inline `#[cfg(test)]` tests.
</objective>
