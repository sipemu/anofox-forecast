<objective>
Fix the MFLES auto-multiplicative runaway (issue #219) at all three failure points in `src/models/mfles.rs` and prove the fix with a committed before/after regression on the #219 repro series (near-zero month, level ≈ 2k; currently forecasts ~13× level → must forecast ~level).

Three mutually reinforcing guards, all locked in CONTEXT.md:
- MULT-01 (mode guard, D from CONTEXT): auto mode rejects multiplicative when `min/median < τ` (τ = 0.10) → falls back to additive.
- MULT-02 (log floor): before `ln()`, winsorize each value to `v.max(0.01 × median)`.
- MULT-03 (back-transform clamp): cap `exp()` forecast at `10 × in-sample max`, floor at 0, applied ONLY in `predict_internal()`.
- MULT-04 (proof): committed regression test on the #219 repro series.

Purpose: The library's Core Value is "every improvement proven with a before/after number." Issue #219 is a correctness bug where a single near-zero month drives a ~13× forecast blow-up; this phase eliminates it and guards against regression.

Output: Edited `src/models/mfles.rs` (three guards + one new struct field + three private const) and a new committed regression test file.
</objective>
