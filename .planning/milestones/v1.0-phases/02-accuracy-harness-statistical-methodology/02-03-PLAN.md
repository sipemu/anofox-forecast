    Create `crates/anofox-bench-harness/src/dm_test.rs`; add `pub mod dm_test;` to `crates/anofox-bench-harness/src/lib.rs` (update doc-comment module list, BENCH-02/D-09).

    Implement `pub fn diebold_mariano_hln(e1: &[f64], e2: &[f64], h: usize) -> (f64, bool)` returning `(p_value, reject_h0)`:
    - Guard: if `e1.len() != e2.len() || e1.is_empty()` return `(f64::NAN, false)`.
    - `T = e1.len()`. Loss differentials `d_t = e1_t^2 - e2_t^2` (squared-error loss per D-09). `d_bar = mean(d)`.
    - Autocovariance `gamma(k) = (1/T) * sum_{i=k}^{T-1} (d_i - d_bar)(d_{i-k} - d_bar)`.
    - HAC variance: `hac = gamma(0)` when `h <= 1`, else `gamma(0) + 2 * sum_{k=1}^{h-1} gamma(k)`. `V_hat = hac / T`.
    - Guard non-positive `V_hat` (e.g. identical models): if `V_hat <= 0.0` return `(1.0, false)` (no evidence of difference).
    - Raw `DM = d_bar / sqrt(V_hat)`.
    - HLN correction: `factor = sqrt((T + 1 - 2h + h(h-1)/T) / T)`; `S* = DM * factor`. Guard against a negative radicand for tiny T (fall back to `factor = 1.0` when the radicand is <= 0).
    - Two-sided p-value via the normal approximation: `p = 2.0 * normal_cdf(-S*.abs())` (A2/OQ3 — normal approx adequate for M-competition T >= 18; document the approximation in a `//` comment). `reject_h0 = p < 0.05`.

    Implement `fn normal_cdf(x: f64) -> f64` via the Abramowitz-Stegun approximation from PATTERNS.md (std-only; no statrs dependency added).

    Add `#[cfg(test)]` tests for the four `<behavior>` cases.
