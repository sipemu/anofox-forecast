## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-PATH | Tampering | loader.rs `ANOFOX_DATASET_DIR` path handling | medium | mitigate | `load_m3` canonicalizes the dir and joins only fixed hard-coded filenames; no caller-supplied filename component, so `..` cannot escape the corpus dir |
| T-02-NAN | Tampering | loader.rs TSF value parse | low | mitigate | `filter_map` drops unparseable tokens; added `is_finite()` guard drops NaN/Inf so malformed TSF cannot inject non-finite values into metrics |
| T-02-DOS | Denial of Service | loader.rs reading arbitrarily large corpus files | low | accept | Test-only tooling on a maintainer machine with a vendored corpus; no untrusted network input; not worth a size cap |
| T-02-MASE | Tampering (correctness) | src/utils/metrics.rs D-03 fix | medium | mitigate | Period-1 fallback + regression test prevents silent NaN entering aggregates; behavior pinned by `mase_constant_series_no_nan` |

No high-severity threats identified: this plan is local, test-scoped tooling with no auth, network, session, or crypto surface. All V2/V3/V4/V6 ASVS categories are not applicable (see RESEARCH.md Security Domain).
