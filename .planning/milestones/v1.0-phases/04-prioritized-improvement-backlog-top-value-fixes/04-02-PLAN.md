<objective>
Run the time-boxed, best-effort investigation into the AutoETS M3-monthly MASE gap (measured
1.0452 vs statsforecast 2.0.3 reference 0.8633). The research root-cause hypothesis (L3/L4) is that
the harness calls AutoETS::new() without a seasonal period, so seasonal_period defaults to 1 and ALL
seasonal candidates are excluded for monthly data. The first task tests that hypothesis with a
15-minute harness-only change; a decision checkpoint then either LANDS the fix and locks
accuracy.json (Phase-2 deferred lock, now unblocked) or STOPS and keeps accuracy.json deferred.

Purpose: A measured MASE improvement is a bonus IMPR-02 delta; no improvement means the gap stays
#1 in the backlog and accuracy.json stays UNLOCKED. Never force a lock on a failing anchor
(preserves the Phase-2 defer-lock discipline).
Output: A harness change with a measured before/after MASE, and either a locked accuracy.json (if
the anchor passes) or a documented deferred outcome (if it does not).
</objective>
